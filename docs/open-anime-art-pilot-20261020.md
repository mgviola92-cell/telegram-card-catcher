# Open-license anime-style character artwork: FIRST REAL TWO-VARIANT PILOT

Status: **research-stage only** (2026-10-20). No Telegram Bot production
import, no image downloads, no generated images, no database writes. This
is the first review batch that specifically involves actual **anime-style
illustrations** rather than only classic English literary drawings.

**Artwork URLs in `data/commons_anime_style_pilot_candidates.review.json`

- Base: `https://upload.wikimedia.org/wikipedia/commons/0/0e/Wikipe-tan_sailor_fuku.png`

The source author and page license are **indications of a possible lawful
reuse pathway**, NOT permission automatically entered into the bot or an
end-to-end Telegram success. Attribution to Kasuga, original source page,
the chosen actual license link, and share-alike obligations when applicable
must all be retained. If used unchanged, the file itself need not be
re-rendered or transformed. Verify site/image conditions before import.

Wikipe-tan is a community anime/manga mascot, NOT a character from One
Piece, Naruto or another anime franchise. This pilot does **not** establish
that commercial anime pictures/fan art/AI-generated pictures are free.

## Real pipeline integration

The new `data/commons_anime_style_pilot_metadata.stage.json` has **one
pending metadata-only catalog character**, while the candidate file has
**two potential illustrations**. Tests explicitly confirm *zero* approved
artwork and *zero* automatic imported catalog entries. Duplicate pictures
or appearances are never counted as two unique characters.

`app/artwork_credit.py` now renders small, escaped artist/license credits
under both the wild spawn photo caption and the owned photo caption. During
wild spawns the Source page link is deliberately hidden because the Commons
file title reveals the answer. After catching, the original file source is
shown. The credits are native Telegram HTML, **not a card image**.

The additive schema stores `artwork_author`, `artwork_license_name`,
`artwork_license_url` and `artwork_page_url` **only in shared artwork
tables** `characters` / `character_variants`, never in `owned_cards`.
One original image URL + one optional cached Telegram `file_id` remains
shared among everyone owning that character's particular artwork.

The reviewed base-character importer, variant importer and manual review
assembler preserve attribution when supplied and reject partial/mismatched
credits between input and independent approval manifest. Older rows without
credit fields remain supported for backward compatibility (they must be
reviewed before republishing any CC artwork). Human review still must
evaluate source terms, subject match, source license, content suitability,
and Telegram photo reachability.

**Example for later manual reviewers (NOT APPROVED FOR IMPORT):**

```json
{
  "artwork_author": "Kasuga",
  "artwork_license_name": "CC BY-SA 3.0",
  "artwork_license_url": "https://creativecommons.org/licenses/by-sa/3.0/",
  "artwork_page_url": "https://commons.wikimedia.org/wiki/File:Wikipe-tan_sailor_fuku.png"
}
```

The exact values, like all corresponding rights-evidence fields, require
independent review. The repository intentionally does not ship a fake
`status=approved` import manifest for these candidates.

## Remaining human/operational checks

1. Check the exact Commons files at current version, credits, chosen license,
   contextual trademark/branding restrictions if any, and local suitability.
2. Verify public original HTTPS image delivery through an actual Telegram
   photo upload from a deliberately small consenting test group. Metadata
   API/CI tests alone do **not** prove Telegram can fetch the image.
3. Fill in human review and exact permission manifests, credit fields,
   identity and audience assessments, and approval references. Do NOT
   autoapprove based on file name, image metadata, an AI label or this note.
4. Import only after explicit authorization, first into disposable PostgreSQL,
   then consider carefully controlled production rollout and monitor quota.
5. Continue finding more legitimately reusable art *per character*, not
   equating 148,604 ACDB identifiers with rights-cleared pictures.
